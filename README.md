# librarian
Librarian is a meta-skill: a skill that manages other skills. More specifically, it’s a personal knowledge curator. It finds and loads skills, creates new ones, and helps refine them by saving useful corrections and preferences.

## Install in ChatGPT

[Download Librarian v0.1.3](https://github.com/wrabbit23/librarian/raw/refs/heads/main/downloads/librarian-v0.1.3.zip), then upload the ZIP through ChatGPT's Skills interface.

Each release includes a validated installable ZIP. `release.json` identifies the version, exact source commit, archive path, and SHA-256 checksum.
